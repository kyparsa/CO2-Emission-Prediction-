# 🚗 CO2 Emission Prediction Project

Predicting vehicle fuel consumption and carbon dioxide emissions using Machine Learning.

## 📊 About the Project

In this project, various artificial intelligence algorithms were used to predict fuel consumption and CO2 emissions from vehicles. The data has been cleaned and new features (Feature Engineering) have been created.

## 🤖 Models Used and Their Accuracy:

* **Gradient Boosting:** 97.52% 🚀
* **Random Forest:** 96.99% 🌲
* **Ridge Regression:** 87.19% 📈
* **Linear Regression:** 87.18% 📉
* **Lasso Regression:** 87.04% 📉

## 🛠️ Technologies Used:

* Python 🐍
* Scikit-Learn
* Pandas & NumPy
* Matplotlib & Seaborn
